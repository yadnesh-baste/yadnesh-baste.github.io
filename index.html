Projects

Three case studies on public data, each with code you can run. Every result below is reproducible from the repository.

Machine learning for manufacturing quality

Which production runs will fail? An honest test on 590 sensors

Many published models for this dataset report over 90% accuracy, yet a model that passes every run is already 93% accurate. I rebuilt the problem the way a factory would face it: learn from past runs, predict the next ones.

Inspecting the riskiest 10% of runs catches 22% of failures, about twice the rate of random checks. A shuffled split would have overstated the model.

Read the case studyCode on GitHub

Python, pandas, scikit-learn, LightGBM, time-based validation

Customer analytics for retention

Who leaves a bank, and whom to call first

Ten thousand retail-bank customers in France, Germany and Spain. I segmented churn, built a risk model and turned it into a call list a retention team could work through, the same question I worked on at Bajaj Finance.

Calling the riskiest 20% of customers reaches 65% of those who would leave. German customers churn at twice the rate of French and Spanish ones.

Open the interactive dashboardCode on GitHub

Python, LightGBM, logistic regression, Power BI data model and DAX

Business process design

From IT request to portfolio decision, modelled in BPMN 2.0

At PowerCo I designed a demand-to-portfolio process for IT requests from seven departments. This is a public, anonymised version of the pattern: who does what, where requests stall, and how priorities become transparent.

One intake, a completeness check before anyone estimates effort, and a scoring model the portfolio board can explain.
